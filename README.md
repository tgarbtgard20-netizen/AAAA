# نظام مؤسسة هجاير للتجارة — نقاط البيع والمحاسبة والباركود (Hajayer POS System)

نظام متكامل واحترافي لإدارة المبيعات ونقاط البيع (POS)، المخزون، الحسابات، طباعة الفواتير الحرارية، وطباعة ملصقات الباركود، مع دعم كامل لقارئات الباركود الليزرية واللاسلكية وكاميرات الأجهزة.

---

## 🚀 كيفية تشغيل المشروع على جهازك في VS Code

### 1. المتطلبات الأساسية
- تثبيت برنامج **Node.js** (الإصدار 18 أو 20 أو أحدث) من الموقع الرسمي: [nodejs.org](https://nodejs.org)
- تثبيت محرر الأكواد **Visual Studio Code**: [code.visualstudio.com](https://code.visualstudio.com)

### 2. خطوات الفتح والتشغيل في VS Code

1. قم بفك ضغط ملف `hajayer-pos-system.zip` على جهازك في مجلد خاص (مثلاً في مجلد المشاريع أو على سطح المكتب).
2. افتح برنامج **VS Code**.
3. من القائمة العلوية اضغط على **File** ثم **Open Folder...** واختر المجلد الذي قمت بفك الضغط فيه.
4. افتح الطرفية (Terminal) بالضغط على اختصار:
   - في ويندوز: `Ctrl + ~` أو من القائمة العلوية **Terminal** -> **New Terminal**.
5. اكتب الأمر التالي لتثبيت المكتبات:
   ```bash
   npm install
   ```
6. بعد انتهاء التثبيت، اكتب أمر التشغيل:
   ```bash
   npm run dev
   ```
7. سيظهر لك رابط التشغيل المحلي:
   ```text
   ➜  Local:   http://localhost:3000/
   ```
   اضغط على الرابط أو افتحه في متصفحك (Google Chrome أو Microsoft Edge).

## ⚡ خيار التشغيل المباشر بنقرة واحدة (بدون أوامر)

- لمستخدمي **ويندوز (Windows)**:
  - يمكنك ببساطة النقر المزدوج على ملف `run.bat` المرفق مع المشروع ليقوم بتثبيت الحزم وتشغيل النظام وفتح المتصفح تلقائياً!

- لمستخدمي **ماك أو لينكس (Mac / Linux)**:
  - شغل الأمر `./run.sh` في الطرفية.

## 🎯 ميزات النظام الرئيسية
- **دعم كامل لقارئ الباركود (Barcode Scanner Gun)**: تم تضمين حقل استقبال ثابت ومخفي يستقبل قراءات أجهزة الليزر اللاسلكية والـ USB تلقائياً بدون الحاجة للنقر داخل أي حقل.
- **طباعة الفواتير الحرارية (80mm)**: فاتورة متوافقة مع متطلبات هيئة الزكاة والضريبة والجمارك (ZATCA) متضمنة رمز الاستجابة السريعة QR ورقم الواتساب للتواصل (+966 56 340 9344).
- **الخصم الموحد والمرن**: خياران للخصم (الخصم بالصنف أو الخصم بالإجمالي) مع إظهار خانة الخصم الموحدة بوضوح في الفاتورة.
- **طباعة ملصقات الباركود**: أداة مخصصة لطباعة بطاقات الأسعار وملصقات الباركود لرفوف المتجر.
- **العمل دون إنترنت (Offline)**: حفظ كامل للبيانات محلياً على المتصفح مع إمكانية أخذ نسخة احتياطية واسترجاعها في أي وقت بنقرة واحدة (JSON).
- **تطبيق PWA قابل للتثبيت**: يمكن تثبيته كبرنامج مستقل على سطح المكتب أو جوالات أندرويد.
